1 · running it

Running it

No hardware

The whole program against a modelled bench. This is how the console and the pipeline logic are developed.

bash scripts/setup.sh                    # installs .[service,dev], runs the suite
python -m bace.service --sim --fast --port 8900 --ui ui/
  • --sim builds the rig from bace.drivers.simulated. pyvisa is never imported.
  • --fast makes every settle a no-op. It is refused without --sim: on a real rig it would measure before the device had settled, with no symptom in the data.
  • --seed N varies the simulated device. --ui ui/ serves the console at the same origin, so no CORS and no proxy.
  • Run from the repo root. rig.toml and run.toml are found by name in the working directory; elsewhere you silently get built-in defaults.
  • --host is refused unless it is a loopback address. If a sandbox needs 0.0.0.0, put a proxy in front.

Lab PC, real instruments

Install both extras, then bring the bench up in stages. Each stage sends its SCPI and reads the instrument's error queue immediately after, so the report lists exactly what was rejected.

py -3 -m pip install -e .[lab]          # = .[rig,service]

py -3 -m bace.bench                  # offline, discover, local. Only *IDN?
py -3 -m bace.bench --read           # what each instrument is set to
py -3 -m bace.bench --configure      # send configuration. Outputs stay OFF
py -3 -m bace.bench --acquire        # one scope acquisition
py -3 -m bace.bench --sync           # where the pulse sits in the LED cycle
py -3 -m bace.bench --dio            # toggle shutter and relay. Audible
py -3 -m bace.bench --outputs        # enable outputs. NO SAMPLE CONNECTED
py -3 -m bace.bench --measure        # one real transient. Needs a sample

py -3 -m bace.service --rig rig.toml --run run.toml --ui ui/
  • PyVISA drives the NI-VISA already installed for LabVIEW, so GPIB needs no new stack.
  • Reports land in bench-reports/ as .txt, .html and .json. The .json holds the full command transcript.
  • Pass 1 prints a code fingerprint, a hash over every .py in the package. There is more than one copy of this tree on the bench.
  • Nothing that can put a voltage on the device node runs without an explicit flag and a typed confirmation.

On the lab PC, by double-click

Three files in scripts/ are the whole workflow. Each changes to the repo root first.

stepfiledoes
1 · onceSetup.batinstalls the package into py -3. Setup (sim).bat on a machine with no instruments
2 · new benchRun Bench Check.batthe staged check-out, pass 1: package, simulated runs, *IDN? at every address. Touches nothing
3 · every dayRun Service.batthe service and the console at 127.0.0.1:8900. Run Service (sim).bat for the simulator

The other six — Run Sync Check, Run DIO Check, Run Shutter, Run Light Power, Run Bare BACE, Run LabVIEW Replica — are diagnostics for the bench itself, used while it was being brought up. One instrument or one transient at a time, no service. Not part of a measurement day.

Checks

python -m pytest -q                  # the suite
python -m examples.demo_scan         # a simulated transient scan
python -m bace.bench                 # the offline stages only

test_dio_backend_explains_itself_when_neither_route_works fails wherever a 64-bit delib64.dll is installed: it makes the DIO backend findable where the test needs it absent. Environmental. There is no DELIB on Linux.

3 · architecture

Architecture

Layers

Each layer may import the ones below it and nothing above.

The event stream

In the VI, the measurement loop wrote its own files. run_transient_scan() yields typed events and writes nothing; everything that wants the data subscribes.

Instrument protocols

Eight typing.Protocol definitions state what the experiment may ask of an instrument. Nothing inherits; a class satisfies a role by having the methods. That is how --sim works.

protocolon the benchwith --sim
BiasSourceAgilent 81150Aa modelled pulser
DigitizerInfiniium DSO9054Hsynthetic traces
SourceMeterKeithley 2400a diode model
LedSourceAgilent 33220Alevels and polarity
ShutterDeditec DIO, module 0a boolean
RouterDeditec DIO, module 1an interlocked boolean
PowerMeterNewport 1918-Ca lamp curve
TemperatureControllerLake Shore 331settles instantly

The 1918-C and 331 drivers are in this repo and the service opens both, so it needs no other program running. The standalone consoles under examples/ are an escape hatch.

Configuration

fileholdsif it goes stale
rig.tomlthe bench: addresses, the 5.192 Ω sense resistor, ×4 amp gain, sign convention, sync latencyevery charge is silently rescaled
run.tomlthe measurement: averages, timebase, integration window, settle times, the axisyou repeat a run you did not mean to

Both are copied verbatim into every output file, and both are found by name in the working directory.

Parameter provenance

A run is thirty-odd numbers, and the same number can arrive by six routes. The console shows the value and which layer won.

Process model

The 331 answers only the last query it received, and the GPIB bus has one master. One process opens the instruments; everything else talks to that process.

6 · the console

The console

Four tabs. Every screen is a fold of one GET /bench snapshot and the /events socket; no view talks to an instrument.

ui/replay.html feeds recorded fixtures into the same store the socket feeds, and ui/preview.html is the bench tab over a stub API, so the console can be worked on with no service. ui/README.md maps every file.
