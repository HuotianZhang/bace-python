# Troubleshooting

Symptoms, their causes and the remedy, by area. A warning in the console states its own evidence and remedy; this chapter covers what the console cannot see.

## The service and the console

| Symptom | Cause | Remedy |
|---|---|---|
| The console says `offline` in its footer | The service is not running, or runs on another port | Start it (1.3); the console reconnects by itself. |
| The service exits at start with an address error | Another process holds port 8900 | Close the other service, or start this one with `--port`. |
| Values on the rail look old after a run | The rail shows the last read-back, taken at service start, at the start of each run and after each bench action, overlaid with the state the running step implies and the newest temperature | Any bench action, such as a fix on the chain strip, reads the bench again. |
| A parameter differs from `run.toml` | A higher layer holds another value: the last-used layer from the journal, or an edit | Reset removes an edit and shows the next layer down. A last-used value is replaced by the next run that sets the parameter. |

## Instruments not reachable

| Symptom | Cause | Remedy |
|---|---|---|
| An instrument reads "not reachable" | It is off, its cable is loose, or another program holds it | Check power and cable; close LabVIEW and every other bench tool. |
| The 1918-C reports "no Newport device found" | The meter's own console holds the USB device | Close that console, or name it in `rig.toml [power_meter] console`. |
| The 331 returns implausible readings | The 331 console also holds GPIB address 7, and each reads the other's replies | Close the 331 console, or name it in `rig.toml [temperature] console`. |
| The shutter or relay does not move | The DIO driver does not match the Python build, or the relay interlock refuses while a source is on | `python -m bace.bench --dio` reports which; switch the sources off before moving the relay. |

## Trigger and timing

| Symptom | Cause | Remedy |
|---|---|---|
| Q close to zero and traces of noise only | Nothing triggers the digitiser; with `trigger_sweep = AUTO` it records untriggered noise | Check the chain strip; check the 81150A Sync cable to CHAN3. |
| The 33220A polarity fix is refused | Its output is on | `led-off`, then the fix. |
| Spike-edge warnings on many shots | The trigger level sits on a slope of the Sync, or the Sync is noisy | Leave `calibrate_trigger` on; check the Sync cable. |

## Signals

| Symptom | Cause | Remedy |
|---|---|---|
| Rail warnings | The signal exceeds the vertical range | Reduce the magnitude of V_coll or the LED level. |
| Light − dark settles to a non-zero level | Different baselines or device states between the traces | Use the pre-trigger baseline (`offset_region = pre-trigger`); check that the settle times are long enough at this temperature. |
| Q scatters more than usual between loops | Drift between the two traces of a shot | `alternate_order` on; shorter settle times; more loops. |
| Q has the wrong sign | The polarity pair, or the measurement chain's sign convention | Check `invert_polarity` with `output_polarity` against 2.2, and `current_sign` in `rig.toml`. Never correct a sign with the generator's polarity switch, which changes the voltage the device sees. |

## Temperature

| Symptom | Cause | Remedy |
|---|---|---|
| A temperature node never settles | The tolerance is tighter than the controller holds, or the heater range is off | Widen `tolerance_k`, or set the heater range on the 331's front panel. |
| A setpoint is refused | It is above `max_setpoint_k` | Lower it, or raise the limit in `rig.toml` if the cryostat allows. |
| The temperature reads "stale" during a run | Monitor readings pause while a run holds the bus lock | Expected; readings resume when the run pauses or ends. |
