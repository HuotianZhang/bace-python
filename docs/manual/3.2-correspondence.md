# Principle, hardware and code

Each step of a measurement traced from its physical purpose to the instrument command and the code that sends it. Commands are SCPI as written by the drivers; channel 1 of the 81150A, CHAN2 (current) and CHAN3 (Sync) of the digitiser.

## Before the shots

Done once per run of the `bace` module, in this order: the first three in `service/modules.py` `_build_bace`, the rest in `experiment/transient.py` `run_transient_scan`.

| Step | Purpose | Instrument and command | Code |
|---|---|---|---|
| V_oc, with `measure_dc` | The prebias the axis is centred on (2.1) | 33220A `:VOLT:OFFS` = `level_v`; relay to the 2400, which sources 0 A: `:SOUR:FUNC:MODE CURR`, `:SENS:FUNC 'VOLT:DC'`. J_sc and J_sat are measured with it. Without `measure_dc`, V_oc is typed, taken from a preceding `jv_bace` node or from the session. | `drivers/agilent33220a.py` `set_dc`, `drivers/keithley2400.py` `measure_voc`, `drivers/routing.py` |
| Same drive for both | V_oc and the shots must see the same light | Refused otherwise | `core/illumination.py` `assert_axis_centre` |
| LED as pulse | Light on for half of each 2 ms cycle; light off is the edge extraction follows | 33220A `FUNC:SHAP PULSE`, `:FREQ 500`, `FUNC:PULS:DCYC 50`, `:VOLT:HIGH` = `level_v`, `:VOLT:LOW` = `low_level_v` (below the LED threshold), `:OUTP:POL INV`. The Sync is not inverted, so its rising edge is light off. | `agilent33220a.py` `set_pulse`, `set_polarity` |
| Relay | Device to the amplifier and the digitiser | DIO module 1, channel 0 = 0 | `routing.py` `transient()` |
| Record | 1 µs before the trigger, 9 µs after it | DSO9054H `:TIM:RANG`, `:TIM:POS`, `:ACQ:POIN` | `drivers/infiniium.py` `configure_timebase` |
| Arm | One bias step per LED cycle, at light off | 81150A `:ARM:SOUR1 EXT`, `:ARM:SLOP POS`; the first light levels, output on | `drivers/agilent81150.py` `configure_trigger`, `set_levels` |
| Trigger | t = 0 at the 81150A Sync (2.2) | `:TRIG:EDGE:SOUR CHAN3`, `:TRIG:EDGE:SLOP POS`, `:TRIG:HTHR` at half the Sync peak with `calibrate_trigger` | `infiniium.py` `configure_edge_trigger` |

## One shot

The light trace first; with `alternate_order` the dark trace comes first on even loops.

| Step | Purpose | Instrument and command | Code | Manual |
|---|---|---|---|---|
| 1 Light levels | Hold V_pre, step to V_coll after t_d, for `pulse_width_ns` | 81150A `:VOLT1:HIGH`, `:VOLT1:LOW`, `:PULS:DEL1` = t_d, `:FUNC1:PULS:WIDT` | `core/pulses.py` `pulse_levels`; `agilent81150.py` `set_levels` | 2.1 |
| 2 Shutter open | Light on the sample | DIO module 0, channel 0 = 1 | `drivers/shutter.py` `unblock` | |
| 3 Settle | Steady state at V_pre under light | `settle_s` + `shutter_settle_s` | `experiment/transient.py` | 2.3 |
| 4 Light power | A record of the LED during the run | 1918-C read over USB | `drivers/newport1918c/` | |
| 5 Range | Fit the trace to the vertical range | `:CHAN2:OFFS`, `:CHAN2:RANG`, iterated with single acquisitions | `infiniium.py` `autorange` | 2.3 |
| 6 Clear the averager | No acquisition of the previous trace in this one | `:STOP`, `:ACQ:AVER OFF`, `:CDIS`, `:ACQ:AVER ON`; a count other than 0 from `:WAV:COUN?` stops the run | `infiniium.py` `_reset_averager` | 2.3 |
| 7 Acquire light | N_avg cycles averaged into one trace | `:DIG`, `*OPC?`; a count from `:WAV:COUN?` below N_avg stops the run. A digitiser that does not answer the count is not checked. | `infiniium.py` `acquire` | 2.3 |
| 8 Fetch | Voltage across R_s to current | `:WAV:SOUR CHAN2`, `:WAV:DATA?`; I = `current_sign` · V_s / R_s | `infiniium.py` `_fetch` | 2.3 |
| 9 Sync trace | The trigger edge of this trace, for the timing check | `:WAV:SOUR CHAN3`, `:WAV:DATA?` | `transient.py` `_sync_trace` | 4.2 |
| 10 Dark levels | The dark reference | `translated`: write `high_dark`, `low_dark` from `pulse_levels` and wait `dark_settle_s`. `same`: the light levels stay, and the wait is skipped when the light trace came first. | `transient.py` `dark_part`, `pulses.py` | 2.1 |
| 11 Shutter shut | No light | DIO module 0, channel 0 = 0; wait `shutter_settle_s` | `shutter.py` `shut` | |
| 12 Acquire dark | Same range as the light trace, so both share one zero | Steps 6–9 without the range step. After a light trace the range stays; a dark trace taken first is given the range this point's light trace had on the previous loop. | `transient.py` `take`, `infiniium.py` `acquire` | 2.3 |
| 13 Light − dark | Remove the displacement current and the zero offset | I_light − I_dark, then with `offset_correct` minus I_0 from the region `offset_region` names: before the trigger, or the last 10 % of the record | `core/process.py` `photocurrent` | 2.3 |
| 14 Window | Place the integral on the field arrival | t_d + `trigger_offset_s` + `t0_int_s` − `trace_t0`, for `t_int_width_s` | `transient.py` `resolve_window` | 2.2 |
| 15 Charge | Q of the shot | Σ (light − dark − I_0) Δt over the window | `process.py` `charge` | 1.1 |
| 16 Diagnostics | Is the shot what it claims to be | Spike lag and edges, Sync lag, rail, averages, late offset | `core/diagnostics.py`; verdicts in `service/wire.py` | 4.2 |

The ×4 amplifier inverts. With `invert_polarity = true` the generator levels are swapped and negated before they are written, and with `:OUTP1:POL NORM` the device then rests at V_pre and steps to V_coll. The generator's low level holds the device between steps; the levels at the generator are the device voltages divided by `pulse_amp`.

After the last shot, and on any stop or failure, `experiment/rig.py` `park` turns the 81150A and 2400 outputs off and shuts the shutter.

## Parameters

The `run.toml` keys that reach an instrument, and the chapter that explains each. Chapter 4.1 lists every parameter.

| Key | Becomes | Manual |
|---|---|---|
| `[axis]` `name`, `start`, `stop`, `step`, `centre_on_voc` | The V_pre, V_coll or t_d of each point | 1.3 |
| `[pinned]` `vcoll` | 81150A level, / `pulse_amp` | 2.1 |
| `[pinned]` `delay_ns` | `:PULS:DEL1` | 2.2 |
| `n_averages` | `:ACQ:AVER:COUN` | 2.3 |
| `timebase_ns_per_div`, `record_length` | `:TIM:RANG` (×10), `:TIM:POS` (×4), `:ACQ:POIN` | 2.2 |
| `t0_int_s`, `t_int_width_s` | The integration window; no instrument | 2.2 |
| `pulse_width_ns` | `:FUNC1:PULS:WIDT` | 2.2 |
| `pulse_frequency_hz`, `duty_percent` | 33220A `:FREQ`, `FUNC:PULS:DCYC` | 1.2 |
| `offset_correct`, `offset_region` | The baseline; no instrument | 2.3 |
| `alternate_order` | The order of the two traces | 2.3 |
| `dark_reference` | The dark levels | 2.1 |
| `invert_polarity`, `output_polarity` | The sign of the levels; `:OUTP1:POL` | this chapter |
| `settle_s`, `dark_settle_s`, `shutter_settle_s` | Waits | 2.3 |
| `external_trigger`, `trigger_slope_positive` | `:ARM:SOUR1`, `:ARM:SLOP` | 2.2 |
| `trigger_sweep`, `calibrate_trigger` | `:TRIG:SWE`, `:TRIG:HTHR` | 1.5 |
| `[illumination]` `level_v`, `low_level_v` | 33220A `:VOLT:OFFS` for V_oc; `:VOLT:HIGH`, `:VOLT:LOW` for the shots | 1.2 |

`rig.toml` holds what describes the bench rather than the measurement: addresses, `sense_resistor_ohm`, `pulse_amp`, `current_sign`, `trigger_offset_s`, channel assignments and limits.

## Recorded quantities

The fields of the HDF5 file (3.3) that are computed rather than measured.

| Field | Computed as | Code |
|---|---|---|
| `/charge/q` | Q of each shot, (loop, point) | `process.py` `charge` |
| `/charge/mean`, `/charge/std` | Mean and sample standard deviation of each point's acquired shots, including an unfinished loop | `process.py` `ChargeAccumulator`, `storage/recorder.py` |
| `/traces/light`, `/traces/dark` | Each point's traces averaged over loops | `process.py` `RunningAverage` |
| `/traces/photocurrent` | light − dark of the averaged traces, less I_0 with `offset_correct` | `process.py` `photocurrent` |
| `/traces/window` | The window of each point in record time | `transient.py` `resolve_window` |
| `/traces/trace_t0` | `:WAV:XOR?`, the record's origin relative to the trigger | `infiniium.py` |
| `/diagnostics/*` | Per shot: averages counted, spike lag, spike and Sync edges, Sync lag, the levels before the trigger, late offset, `dark_first` | `core/diagnostics.py`, `storage/recorder.py` |
| `/axis/voc` (attribute) | The V_oc the axis was centred on: measured with `measure_dc`, typed, or from a `jv_bace` node or the session | `service/modules.py` `_build_bace` |
| `/intensity/mean`, `/intensity/std` | Light power per point over the loops | `storage/recorder.py` |
