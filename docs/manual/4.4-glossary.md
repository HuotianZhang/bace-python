# Glossary

One name, one symbol and one unit per term. Code names are given where they differ.

## Measurement

| Term | Symbol | Unit | Code | Definition |
|---|---|---|---|---|
| shot | | | | One light trace and one dark trace at one point. |
| point | | | | One value of the scan axis. |
| loop | | | `n_loops` | One pass over every point. |
| run | | | | One module, or one pipeline, from Start to the end. |
| light trace | | | | The current recorded through the bias step, with the device in steady state under illumination until the step; the LED switches off at the step. |
| dark trace | | | | The current recorded for the reference step, shutter shut. |
| dark reference | | | `dark_reference` | The voltage step the dark trace repeats: `translated` keeps the voltage change of the light step but starts at 0 V; `same` uses the light step's initial and final voltages. |
| prebias | V_pre | V | `vpre` | The voltage held under illumination before the step; normally V_oc. |
| collection voltage | V_coll | V | `vcoll` | The reverse voltage the device is stepped to. The literature also calls it V_extr. |
| open-circuit voltage | V_oc | V | | The steady-state terminal voltage at zero external current under the illumination used. |
| delay | t_d | ns | `delay_ns` | The time from the trigger to the bias step, as set on the 81150A (`:PULS:DEL1`). |
| field arrival | | s | | The time the voltage step reaches the device: trigger time + t_d + `trigger_offset_s`. |
| extraction current | I(t) | A | | The current in one trace, I(t) = `current_sign` · V_s(t)/R_s, with V_s the voltage CHAN2 records. |
| extracted charge | Q | C (shown in nC) | `q_mean` | The integral of I_light − I_dark over the integration window, after the baseline is subtracted. |
| integration window | | s | `t0_int_s`, `t_int_width_s` | The interval over which I_light − I_dark is integrated: it starts at `t0_int_s` relative to the field arrival and lasts `t_int_width_s`. |
| baseline | | A | `offset_correct`, `offset_region` | The constant subtracted from light − dark before integration. |
| carrier density | n | m⁻³ | | The mean density of extracted carriers, n = \|Q\|/(eAd), with e the elementary charge, A the device area and d the active-layer thickness. Valid under the conditions of 2.4. |
| generation rate | G | m⁻³ s⁻¹ | | Carriers generated per volume and time under the LED; estimated as J_sc/(ed). G = 0 is the dark. |
| recombination order | δ | | | The exponent in R = k_δ n^δ, with R the recombination rate. At V_oc, d ln G / d ln n estimates δ when n is the bulk density and surface recombination is negligible (2.4). |
| geometric capacitance | C_geo | F | | The capacitance of the active layer between the electrodes. |
| built-in voltage | V_bi | V | | The equilibrium potential difference across the active layer. Neglecting space charge, the field at applied voltage V is about (V_bi − V)/d. |
| mobility | μ | m² V⁻¹ s⁻¹ | | Drift velocity per field of a carrier. |
| transit time | t_tr | s | | The time a carrier needs to cross the layer, d²/(μ(V_bi − V_coll)). |
| displacement current | | A | | The current that charges the device's capacitance when the bias steps. With the first carriers extracted, it forms the spike at the start of both traces. |
| drift | | A | `late_offset_ua` | A change of the measurement chain between the two traces of a shot, seen as a late level of light − dark that the baseline does not remove. |
| null run | | | | A run with the shutter shut for both traces and `dark_reference = "same"`, so the two traces differ in nothing; its Q measures the chain's own error. |

## Instruments and signals

| Term | Symbol | Unit | Code | Definition |
|---|---|---|---|---|
| current conversion factor | R_s | Ω (V/A) | `sense_resistor_ohm` | The ratio of the voltage at CHAN2 to the device current, set by the sample-holder amplifier and the 50 Ω input path: 5.192 Ω for the present amplifier. Called the sense resistor in the code and `rig.toml`. |
| bias amplifier | | | `pulse_amp` | The ×4 amplifier on the sample holder between the 81150A and the device. |
| light amplifier | | | | The ×4 amplifier between the 33220A and the LED. |
| hardware averages | N_avg | | `n_averages` | Acquisitions the digitiser averages into one trace. |
| record | | | `timebase_ns_per_div`, `record_length` | The digitiser's acquisition: ten divisions, one before the trigger. |
| LED level | | V | `level_v` | The 33220A high-level output that drives the LED. The V_oc measurement uses the same setting. |
| settle time | | s | `settle_s`, `dark_settle_s`, `shutter_settle_s` | Waits before acquiring, after levels or the shutter change. |

## Software

| Term | Definition |
|---|---|
| service | The process that owns the instruments and serves the console (`python -m bace.service`). |
| console | The browser interface the service serves. |
| module | One kind of measurement or action: `bace`, `jv`, `light`, `temperature`, … |
| pipeline | A tree of modules and loops run as one. |
| Dry run | Validation of a pipeline against the bench without touching an instrument. |
| read-back | The service's reading of every instrument's state. |
| layer | Where a parameter value comes from: default < run.toml < last used < edited. |
| journal | The append-only record of a session. |
| park | The safe state: bias and source-meter outputs off, shutter shut. The LED keeps running behind the shutter. |
