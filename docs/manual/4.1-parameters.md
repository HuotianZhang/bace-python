# Parameters

Every parameter of every module: the label the console shows, its default in the code, unit, limits and meaning, and the `run.toml` key that sets it. A value from `run.toml`, the last run or an edit overrides the default (3.1). Rig-dependent defaults are those of a `rig.toml` with no entries.

Generated by `tools/build_manual.py` from the parameter specs in `bace/service/modules.py`. Do not edit by hand: change the code and run the tool again.

## light

Kind: utility.

| Label | Parameter | Default | Unit | Limits | run.toml | Meaning |
|---|---|---|---|---|---|---|
| Shutter | `shutter` | `"leave"` |  | `open`, `shut`, `leave` |  | Open, shut, or leave the shutter where it is. The shutter is the light switch: it is what decides whether light reaches the sample, whatever the generator is doing. |
| LED mode | `led_mode` | `"leave"` |  | `dc`, `pulse`, `off`, `leave` |  | `dc` for a steady level (a J-V under light, a V_oc), `pulse` for the transient's square wave, `off` to disable the output, `leave` to touch nothing. Prefer the shutter over `off`: a generator that is cycled loses its thermal steady state and the next module waits for it all over again. |
| LED level | `led_v` | `1` | V |  | `illumination.level_v` | The 33220A drive level: its DC offset under `dc`, its pulse high level under `pulse`. The same number the V_oc must be measured at and `bace` must pulse at -- the coupling invariant is one level, in one place. |
| LED low level | `led_low_v` | `0.4` | V |  | `illumination.low_level_v` | The 33220A pulse low level, below the LED threshold so the dark half-cycle is dark. `pulse` only. |
| Pulse frequency | `pulse_frequency_hz` | `500` | Hz | ≥ 0 | `acquisition.pulse_frequency_hz` | The rate the 33220A chops the LED at, and the only instrument this value reaches (`pulse` only -- the node itself still moves the shutter). 500 Hz is the bench's operating rate. It holds only until something else sets it: a `bace` writes its own frequency to both generators, so this does not constrain the scan after it. |
| Duty cycle | `duty_percent` | `50` | % | 0 to 100 | `acquisition.duty_percent` | The 33220A's duty cycle: the fraction of the period at the waveform's high level, so at 50 % the device gets 1 ms of light then 1 ms of dark at 500 Hz (`pulse` only). Away from 50 %, read it inverted -- this rig runs the generator at `:OUTP:POL INV`, which flips which half is lit, so the lit fraction is `100 - duty_percent` and raising this shortens the illumination. Whether the lit half is long enough for the device to reach its light V_oc is the operator's call: nothing checks it. |
| Settle after | `settle_s` | `0` | s | ≥ 0 |  | Wait after the light is set, before the node finishes -- so the step that follows starts under a settled lamp. 0 does not wait; the power meter's own agreement check belongs to `bace`, which is the module that needs it. |
