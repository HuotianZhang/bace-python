## 已定（有证据，不再是从手册上推的）

- **判据**：亮态减暗态在**稳态必须回到零**。不是「V_oc 在哪」。四个极性组合里
  只有 ④（纯取负）的动力学曲线正常；② 稳态停在 4.45 mA 恰恰说明它不对。
- **极性代数**（数值验证过）：`output_polarity`(`:OUTP1:POL`) = 纯交换
  (baseline, pulse)；`invert_polarity` = 交换 + 取负；两个一起 = 纯取负。
  不依赖 NORM/INV 那个和数据对不上的标签。
- **放大器 = 反相、增益 4、零偏置**：发生器 `:VOLT1:LOW` → v_pre，
  `:VOLT1:HIGH` → v_coll。02:20 读回的 `(0.505434, 0)` 和
  `pulse_levels(invert=True)` 的暗态形状 `(span/4, 0)` 逐位吻合。
- **`trigger_offset_s = 0`**：同样的 `Delay(ns)=90`，两边的位移尖峰都在 328 ns。
  之前那 47 ns 是从另一条路径量出来的。
- **`timebase_ns_per_div = 200`**：面板上 Timebase 200 ns 和 Pulse Width 5e3 ns
  是并排写着的，两者无关。200 同时让 t0 对上面板的 320 ns（触发 200 + 120）。
- **LED 在 0.4 V 时确实是灭的**：功率计实测，低电平输出是导通电平的 0.009%。
  「光根本没关」这条怀疑排除了。工作光强 20.7 µW。
- **电流 = 电压 / 5.192，只在 `Infiniium._fetch` 里除一次**。`_fetch_volts`
  故意不除（autorange 在电压域工作）；探头衰减交给仪器的
  `:CHAN:PROB:EXT:GAIN`，不在软件里再乘一遍。
- **`:DIGitize` + `*OPC?` 不写任何设置**，取一条完整的平均记录就返回；
  而 `acquire()` 必须重启平均器，否则亮态那条会混进前一条暗态。
- **暗态 = 同样的摆幅、平移到从 0 起步**（`dark_reference = "translated"`）：
  亮 −1.01354 → +1.00000 V，暗 0 → +2.01354 V。摆幅一样，绝对区间不一样。
